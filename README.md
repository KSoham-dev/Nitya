## 🌟 Overview

**Nitya** (meaning *Eternal* or *Daily* in Sanskrit) is a specialized Windows desktop application designed to foster deep concentration. By completely replacing the standard desktop environment with a serene, glassmorphic workspace, Nitya eliminates all digital distractions, allowing you to focus purely on what matters.

## ✨ Features

- 🔒 **Total Lockdown Mode**: Set a strict focus duration with a password-protected exit. Your session stays completely isolated from external system interruptions (blocks Alt+Tab, Alt+F4, and Windows Key).
- 🕉️ **Namjap (Meditation) Mode**: A minimalist, distraction-free counter mode for chanting or meditation. Press `Space` or `Arrow Up` to increment your count against a beautiful, fade-to-transparent background.
- 📚 **Book Mode**: Integrated e-reader capabilities for focused offline reading.
- 🖼️ **Glassmorphic UI**: A stunning, modern interface with smooth micro-animations, tailored color palettes, and glass-like overlays.
- 📊 **Tracker & Reports**: Automatically logs your sessions, goals, book progress, and Namjap counts into a beautifully formatted daily tracker.
- 🚀 **Integrated App Launcher**: Work seamlessly by pinning specific allowed applications or external websites that open inside Nitya’s controlled environment without breaking focus.

## 🛠️ Technology Stack

Nitya is built using a hybrid native/web approach for maximum performance and unparalleled design flexibility:

- **Core Application**: C# WPF (.NET 10.0) with Low-Level Keyboard Hooks for system lockdown.
- **Web Engine**: Microsoft Edge WebView2 for rendering the stunning user interface.
- **Frontend**: Pure HTML, Vanilla CSS, and JavaScript.

## 🚀 Getting Started

### Prerequisites
- Windows 10 or 11
- .NET 10.0 SDK
- WebView2 Runtime (Included in most modern Windows installations)

### Installation
1. Clone the repository:
   ```bash
   git clone git@github.com:KSoham-dev/Nitya.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Nitya
   ```
3. Run the application:
   ```bash
   dotnet run
   ```
